Features

Switch off what you don’t use, and the app stops doing that work entirely.

Overlay layouts and pages don’t need switches: an unused page already costs nothing, because the app only does work for a page while OBS or a browser is holding it open. A Ticker you never added to OBS uses zero resources. The switches below are the background engines — the parts that run all the time, even when nothing is watching.
A switch you changed starts or stops a background engine, which takes a quick restart. It takes about two seconds and every OBS source reconnects by itself.
