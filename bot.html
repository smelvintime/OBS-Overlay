Set up the bot

One click — it signs in through Twitch, nothing to paste.

Twitch will ask which account to connect — sign in as the account the bot should speak as. A separate bot account makes replies look like a bot; your own account works too, if you want them to come from you. If Twitch shows the wrong account, use its “Not you?” link first. Prefer to set it up by hand? The old way still works — it’s in the Twitch guide in the docs folder.

Commands

Switch on the ones you want. Edit the text, then press Enter. Type \n where a reply should split into a separate chat message (up to 5).
OnCommandReplies with Cooldown

Thank new followers

Says thanks in chat when someone follows. Viewers can’t trigger it by typing, each person is thanked once, and a burst of follows becomes one message naming a few people — so it can’t be turned into spam.

Game stats (League)

Reads results straight from the League client on this PC — no account linking, no API keys. Viewers get !record and !rank, and the bot can post the result when a ranked game ends. The record counts ranked only — ARAMs and normals never muddy the grind.
